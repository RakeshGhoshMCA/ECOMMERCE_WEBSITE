# E-Commerce Website

A full-stack e-commerce website built using React and Django REST Framework.

## Technologies

Frontend:
- React
- JavaScript
- Tailwind CSS

Backend:
- Django
- Django REST Framework

Database:
- SQLite / PostgreSQL

## Features

- User Registration & Login
- Product Listing
- Product Search
- Product Categories
- Cart
- Order Management
- Authentication
- REST APIs

## Project Structure

frontend/ → React frontend
backend/ → Django backend

## How to Run

### Backend

cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

### Frontend

cd frontend
npm install
npm run dev
